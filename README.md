# ArtAuth

A decentralized art authentication and provenance tracking platform built on Stacks blockchain. ArtAuth enables transparent artwork verification from artist to collector, ensuring authenticity and maintaining provenance records.

## Features

- **Artist Registration**: Secure onboarding for artists with medium specialization
- **Artwork Registration**: Register artworks with authenticity levels
- **Authentication System**: Multi-party artwork authentication and verification
- **Provenance Tracking**: Complete artwork history and ownership tracking
- **Reward System**: Authenticity-based rewards for verified participants

## Smart Contract Functions

### Admin Functions
- `set-contract-owner`: Transfer contract ownership
- `set-gallery-fee`: Configure gallery fee percentage
- `add-medium-type`: Register new artistic mediums

### Artist Functions
- `register-artist`: Register as a verified artist
- `register-artwork`: Register new artworks for authentication
- `authenticate-artwork`: Verify and authenticate artworks
- `claim-authenticity-rewards`: Claim accumulated authenticity rewards

## Getting Started

1. Deploy the contract to Stacks blockchain
2. Register as an artist with valid medium specializations
3. Register artworks with appropriate authenticity levels
4. Participate in authentication to earn authenticity rewards
